# AI & Machine Learning Foundations

A comprehensive, production-grade repository documenting my 6-month intensive curriculum in Exploratory Data Analysis (EDA), Applied Mathematics, Database Systems, and Algorithmic Machine Learning. 

This repository serves as a practical showcase of data pipeline engineering, statistical analysis, and from-scratch algorithmic implementations.

---

## Repository Structure & Curriculum

### 🔹 Module 1: Data Analysis & Exploratory Data Analysis (EDA)
Focused on data ingestion, programmatic manipulation, web scraping, and deep behavioral visualization.
*   **Environment Foundations:** Jupyter workspace configuration and advanced execution workflows.
*   **Numerical Vectorization:** High-performance array operations and matrix manipulation using NumPy.
*   **Structured Data Engineering:** Tabular data alignment, cleaning, and transformation pipelines using Pandas.
*   **Data Harvesting:** Automated extraction pipelines utilizing programmatic Web Scraping and REST APIs.
*   **Exploratory Visualization:** Statistical distributions, relational mapping, and categorical analysis utilizing Matplotlib and Seaborn.

### 🔹 Module 2: Relational Databases & SQL
Advanced relational database architecture, structural design, and analytical querying.
*   **Database Management:** Schema design, transaction isolation, ACID properties, and execution indexing.
*   **Analytical Querying:** Multi-table relational joins, advanced subqueries, data aggregations, and window functions.

### 🔹 Module 3: Mathematical Foundations for ML
The core mathematical building blocks required to understand objective optimization, gradients, and statistical modeling.
*   **Probability Theory:** Probability distributions, conditional probability, expectation variance, and statistical inferences.
*   **Vector Calculus:** Partial derivatives, chain rules, optimization theory, and gradient behaviors.

### 🔹 Module 4: Machine Learning Implementations
A rigorous look at supervised learning, split cleanly between standard industry library applications and manual algorithmic development.
*   **Supervised Foundations:** Implementation of baseline Classification and Regression models using Scikit-Learn.
*   **Algorithmic Scratch Implementations:** Pure mathematical architecture built from scratch utilizing only NumPy to develop:
    *   *Linear Regression*
    *   *Logistic Regression*
    *   *Naive Bayes Classifier*
    *   *K-Nearest Neighbors (KNN)*
*   **Advanced Supervised Learning:** Non-linear decision boundaries, tree-based classifiers (Decision Trees), and tree pruning optimization techniques.

### 🔹 Module 5: End-to-End Projects
Practical deployment of statistical learning algorithms to solve data-driven industry use cases.
*   **CreditWise Loan Prediction System:** An intelligent classification pipeline analyzing financial applicant profiles (income ratios, credit bureau metrics, collateral evaluation) to automate unbiased risk forecasting and loan approval decisions.
